**DomainX** هي منصة متطورة للوكلاء الأذكياء متعددي التخصصات مصممة خصيصاً للقطاعات الحساسة والمعقدة (**القطاع القانوني، القطاع الطبي والرعاية الصحية، وسلاسل الإمداد والخدمات اللوجستية**). تتفوق المنصة على نماذج الذكاء الاصطناعي العامة عبر دمج محركات القواعد القطعية والمراجع المعرفية الصارمة، مما يضمن دقة متناهية وانعداماً تاماً لمخاطر الهلوسة والامتثال. تتوفر أيضاً طبقة سردية اختيارية تشرح النتائج بلغة واضحة عبر نموذج لغوي محلي مجاني ([Ollama](https://ollama.com))، مع رجوع تلقائي لقالب حتمي إن تعذر الوصول إليه.

**🚀 [التجربة الحية / Live Demo](https://domainx.vercel.app)** — جرّب الوكلاء الثلاثة والملخص الذكي مباشرة من المتصفح دون أي تثبيت. للمزيد راجع النسخة الإنجليزية الكاملة: [`README.md`](README.md#-ai-executive-summary-free-tier-llm-via-ollama).

## 🤖 ثلاثي الوكلاء المتخصصين

### 1. ⚖️ الوكيل القانوني (`LegalAgent`)
- **القطاع المستهدف**: الإدارات القانونية، عمليات الاستحواذ والاندماج، المشتريات المؤسسية، الامتثال.
- **أبرز القدرات**:
  - مراجعة العقود واتفاقيات الخدمات (MSA، NDA، DPA، SLA) مع تقييم درجة خطورة كل بند (منخفض، متوسط، مرتفع، حرج).
  - رصد البنود الخطرة: المسؤولية غير المحدودة، التعويضات غير المتوازنة، وغياب بنود الإنهاء لداعي الملاءمة.
  - صياغة مقترحات التعديل (Redlines) متوافقة مع الاختصاصات القضائية (ديلاوير، نيويورك، القانون الإنجليزي، لوائح الاتحاد الأوروبي GDPR، ومحاكم مركز دبي المالي العالمي DIFC).

### 2. 🏥 الوكيل الطبي والرعاية الصحية (`MedicalAgent`)
- **القطاع المستهدف**: المستشفيات والمراكز الطبية، إدارة دورة الإيرادات (RCM)، دعم القرارات السريرية.
- **أبرز القدرات**:
  - الترميز الطبي الآلي: استخراج رموز التشخيص المعتمدة **ICD-10-CM** ورموز الإجراءات **CPT** من الملاحظات السريرية غير المهيكلة.
  - **محرك التطهير الطبي HIPAA Safe Harbor**: إزالة وتعمية كافة المعرفات الـ 18 للبيانات الصحية المحمية (الأسماء، التواريخ، أرقام السجلات الطبية).
  - الكشف اللحظي عن تداخلات وتعارضات الأدوية الخطرة (مثل خطورة النزيف الحاد عند الجمع بين الوارفارين والأسبرين).

### 3. 📦 وكيل سلاسل الإمداد واللوجستيات (`SupplyChainAgent`)
- **القطاع المستهدف**: التصنيع، مراكز التوزيع، وسلاسل التوريد والتجارة الإلكترونية.
- **أبرز القدرات**:
  - هندسة سياسات المخزون المثلى: حساب كمية الطلب الاقتصادية ($EOQ$)، مخزون الأمان ($Safety Stock$)، ونقاط إعادة الطلب ($ROP$).
  - نمذجة مخاطر الانقطاع وتذبذب فترات التوريد وتركيز الموردين.
  - تقدير انبعاثات الكربون عبر وسائل النقل المختلفة (النقل البري، الجوي، السككي، والبحري).

## ⚡ دليل التشغيل والتركيب المحلي

### المتطلبات الأساسية
- بايثون الإصدار `3.10` أو أحدث.

### 1. الاستنساخ وتثبيت الحزم
```bash
git clone https://github.com/asadullah48/domainx.git
cd domainx
pip install -r requirements.txt
```

### 2. تشغيل الخادم المحلي
```bash
uvicorn domainx.server:app --reload --port 8002
```
يمكنك استعراض واجهة توثيق Swagger التفاعلية عبر: `http://localhost:8002/docs`

## 🐳 النشر عبر Docker و Kubernetes

### التشغيل عبر Docker Compose
```bash
docker-compose up -d --build
```


## 🔌 دليل واجهات برمجة التطبيقات (API Reference)

- `GET /healthz` - فحص صحة الخادم
- `GET /readyz` - فحص الجاهزية والقطاعات النشطة
- `GET /api/v1/domains` - استعراض القطاعات المتخصصة المتاحة
- `POST /api/v1/legal/review-contract` - تنفيذ المراجعة القانونية للعقود وكشف المخاطر
- `POST /api/v1/medical/code-encounter` - الترميز الطبي وتطهير البيانات وفق معايير HIPAA
- `POST /api/v1/supply-chain/optimize-inventory` - تحسين كميات الطلب ومخزون الأمان والتحليل اللوجستي
- `POST /api/v1/domainx/analyze` - التوجيه الذكي الموحد حسب القطاع
- `POST /api/v1/ai/summarize` - ملخص تنفيذي بلغة واضحة عبر نموذج Ollama المحلي المجاني، مع رجوع تلقائي لقالب حتمي إن تعذر الوصول إليه (التفاصيل في [`README.md`](README.md#-ai-executive-summary-free-tier-llm-via-ollama)).
